How to use: Use the tabs above to move between the four flows. Toggle 🌙/☀️ for theme. On Quick Add, the keypad and category chips are live. All buttons show placeholder confirmations — this is a UX prototype, not a functional build.

Screens included (matches the numbered list in the requirements doc): 0) Welcome/Onboarding 1) Home/Dashboard 2) Quick Add 3) Monthly Report 4) Custom Range Report 5) Category Manager 6) Budget Setup 7) Home Screen Widgets 8) Lock Screen Widget 9) Backup Settings 10) Restore Flow 11) Profile 11a) Edit Profile 11b) Avatar Picker.

New this update: Profile screen with an avatar/photo — tap the pencil on the avatar to open the picker, upload a real photo, or choose from colored initials-avatars (the fallback shown when no photo is set). Edit Profile lets you update name, phone, and email after onboarding. Profile also links into Backup & Restore since account and data settings live together.

Palette: Indigo → Pink gradient (#6366F1 → #EC4899), full light/dark support.
